## 1. What this is

A Harbor task where an agent runs the disruption desk of a fictional airline (Aurora Regional, hub HEL)
for one simulated day through MCP tools. Nine scripted disruptions plus dynamic knock-on delays.
Reward per booking = tier weight × pax × on-time factor (0 at 24 h late; 0 if a deadline is missed).
Score = (V_agent − V_nothing) / (V_reference − V_nothing), with both anchors recomputed from the seed at grading.
The Harbor verifier writes `/logs/verifier/reward.txt` = score clipped to [0, 1] (AfterQuery's required format),
plus `details.json` (raw score, failure-mode counts) and `report.json`.

Key files: `opsdesk/world.py` (scenario), `opsdesk/env.py` (simulator + tools), `opsdesk/reference.py`
(scripted reference, stdlib only, tool-only, also the Harbor oracle), `opsdesk/verify.py` (reward, failure
modes), `opsdesk/mcp_server.py`, `opsdesk/make_harbor.py`, `opsdesk/exploits.py`, `opsdesk/eval.py`,
`opsdesk/export.py`, `opsdesk/agent_gemini.py` (direct REST runner), `web/` (results site, Vercel).

## 5. Commands

```bash
pip install "mcp==1.27.0" requests           # Python 3.11+

# scripted baselines (reference, nothing, stop_early, naive), writes results/<size>/summary.json
python -m opsdesk.eval --size standard --seeds 1 2 3
# plus Gemini agent runs over REST (needs GEMINI_API_KEY in env)
python -m opsdesk.eval --size standard --seeds 1 2 3 --agent gemini-4-argon --runs 1
# exploit suite -> web/data/exploits.json
python -m opsdesk.exploits --size standard --seeds 1 2 3 --json-out web/data/exploits.json
# site data (replays policies + agent transcripts under results/<size>/agents/<model>/seed*_run*/transcript.jsonl)
python -m opsdesk.export
# site: static files in web/, Vercel project "ops-desk-bench" (team 13shreyanshs-projects) auto-deploys main
#   https://ops-desk-bench.vercel.app

# Harbor tasks (commit these; no --dev-ca)
python -m opsdesk.make_harbor --seeds 1 2 3 --size standard        # -> harbor/tasks/ops-desk-standard-seed{1,2,3}
harbor run -p harbor/tasks/ops-desk-standard-seed1 -a oracle       # expect 1.000
harbor run -p harbor/tasks/ops-desk-standard-seed1 -a nop          # expect 0.000
harbor run -p harbor/tasks/ops-desk-standard-seed1 -a opencode -m google/gemini-3.8-flash --api-key-name GEMINI_API_KEY
```

Notes:
* OpenCode needs the key passed with `--api-key-name GEMINI_API_KEY` (plain env export did not reach it).
* On a normal machine (e.g. a Mac with Docker) no `--dev-ca` is needed: the stock image lets Harbor apt-install node and OpenCode.
  `--dev-ca <bundle>` is only for the Claude cloud sandbox (TLS-intercepting proxy, no apt mirror); it preinstalls node + OpenCode over https.
* A full OpenCode run on standard takes roughly 15–40 min depending on the model; agent timeout in task.toml is 10800 s.
* The reference over MCP makes ~20–55k tool calls; the Harbor oracle takes ~4 min.
